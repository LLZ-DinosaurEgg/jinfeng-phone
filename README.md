# 金凤的手机 · Jinfeng's Phone

An interactive iPhone simulation web experience — the phone of Thai actress "Ginny" 金凤 on the premiere night of her drama 《分手代理》.

Self-contained single-file build (`index.html`, ~14MB, all assets inlined).

- Unlock passcode: the premiere date (1022)
- WeChat-style live chat, 6 rounds of real-time conversation
- Incoming call with subtitles script
- 13 apps: WeChat, IG (reels), Photos, Music, Mail, Calendar, Maps, Notes, Clock, Weather and more
- All photos are used with permission for this fan-work demo
